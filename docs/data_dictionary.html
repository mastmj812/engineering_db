oilgas data dictionary

Blue Ox Permian data warehouse (Supabase Postgres + PostGIS). Data flow: Novi Insights (nightly) + Enverus (nightly) + Novi Intelligence (quarterly Snowflake share) → raw schemas → curated matviews → apps and read-only users.

Generated 2026-10-30 from the live catalog · 96 relations · 2,396 columns. Descriptions live in the database as column comments — the same text appears in DBeaver, pgAdmin, QGIS, and Supabase Studio.

Read this first — conventions that change interpretation
  • api10 is the universal well key; Novi↔Enverus join is LEFT(api14, 10) = api10.
  • Formation grouping always uses formation_blueox, never the raw free-text formation.
  • Rates for aggregation are calendar-day; producing-day rates are per-well diagnostics.
  • Novi NPV/IRR columns are a vendor screen, not authoritative economics.
  • SPE percentiles: P10 = HIGH case, P90 = LOW case.
