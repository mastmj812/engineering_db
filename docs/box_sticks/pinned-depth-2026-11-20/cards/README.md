# Cards: sticks pinned on a same-tag producer 150 to 500 ft off their depth

2026-11-20, read-only. 45 cards: every class C stick (35) and the first 5 of class A and of class B by location id, in location-id order.
Open `index.html` for all cards on one page.

**The question on every card:** is the yellow stick a real, undrilled location? **KEEP** = yes, it stays in inventory. **REMOVE** = no, the slot is already used, for one of two reasons: *same well* (the stick's depth is wrong and it is really the well it is pinned on) or *slot taken* (the stick is at a different landing, but the operator's staggered pattern leaves that slot empty on purpose). Until 2026-11-20 REMOVE was written THAT WELL.

How to read a card:

- Left, strike section across the stick (reads W to E for N-S laterals, S to N for E-W). Yellow star = the stick at its target TVD; the shaded band is
  150 ft either side (the generator's same-landing window). Black-ringed dot = the well it is pinned on. Other dots = wells with depth evidence,
  coloured and labelled by tag; hollow = not yet producing. Diamonds = other BOX sticks of the DSU. Dashed lines = each bench's landing in this DSU.
- Right, plan view. Wells with no depth evidence (planned survey, round-100 TVD) are dotted here and never drawn on the section.
- Class A = two landings recorded in the DSU for this bench; B = the well sits at another bench's landing; C = neither.
