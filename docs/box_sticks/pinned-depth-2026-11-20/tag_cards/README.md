**The question on every card:** is the well's tag right?

- **AGREE** = retag to the proposed bench shown on the card.
- **KEEP** = the tag is right as it is.
- Or name the bench it should be (for example `BS2_S`), or `?` for a walk-through.

How to read a card: strike section across the well (W to E for N-S laterals, S to N for E-W). Black-ringed dot = the well under review, labelled with its tag.
Other dots = wells with depth evidence, coloured and labelled by tag; hollow = not yet producing. Grey lines = the geologist's gridded tops at the well
(a witness, not gospel). Red dashed line = median depth of WCA_1 wells within 3 miles. Yellow band = the gridded interval of the proposed bench.
Wells with no depth evidence (planned survey, round-100 TVD) appear dotted in plan view only.
