Proposed 9b rules

Finding: the 9b rule as written (D53 cells per cutoff, judged at ≥ 30 packages) cannot judge anything at holdout size. Median judged cells = 0 on both benches; WCXY per-cutoff cells hold 5–14 packages, BS2_S 16–25. The verdict code reads "nothing judged" as FAIL, so 9b would fail both benches by construction, not on evidence. The rule has to change before 9b, whatever else is decided.
9b rulepasses when the forecast is as good as in tuning (BS2_S / WCXY)passes when the forecast is 10 % high15 % highread
As written: per cutoff, bias + spread4 % / 0 %1 % / 0 %0 % / 0 %vacuous: nothing judged
Pooled across cutoffs, bias + spread16 % / 17 %3 % / 1 %0 % / 0 %a FAIL carries almost no information
Pooled, bias only (±10 %)50 % / 49 %8 % / 2 %1 % / 0 %coin flip for a good forecast
Proposed: pooled, consistent with tuning (every cell's holdout bias inside the frozen P2.5–P97.5 interval)87 % / 85 %39 % / 23 %14 % / 3 %passes a good forecast; catches a 15 % miss 86–97 % of the time
  1. Proposed D99 (Michael's call): 9b scores each bench's holdout POOLED across cutoffs, per stream × horizon. BS2_S: oil + gas at cum-12 and cum-24 (cum-36 reaches 30 packages in 0.3 % of draws). WCXY: oil + gas at cum-12, 24 and 36. A bench PASSES when every cell's holdout package bias lies inside its frozen interval (table above, committed CSVs). That means the holdout behaves like tuning: no over-fit, and the tuning bias stands as the disclosed bias (D59 condition 3).
  2. Reported per cell, not gating: |bias| ≤ 10 % and the scale-free spread vs the benchmark (D53 / D58). At 60–90 packages the spread test passes a good forecast only 60–90 % of the time per cell (7a §4 resolution).
  3. A FAIL means diagnose (7a pattern), never re-tune on the holdout.
Scope: WCA's record (D58 / D59) and the prospective 2026 test (D70) are not affected. The proposal departs from D53's per-cell judging for the BS2_S / WCXY holdouts only, because those holdouts are 3–4× smaller than WCA's. What the consistency rule tests: it asks "is the holdout different from tuning?", not "is the forecast within ±10 %?". The tuning-view bias it carries forward is oil −1.6 / +1.8 % at cum-12 / 24 on BS2_S, and −1.0 / −5.1 / −9.2 % at cum-12 / 24 / 36 on WCXY. WCXY's oil cum-36 at −9.2 % sits close to the D53 tolerance and would be stated on every WCXY workup.
